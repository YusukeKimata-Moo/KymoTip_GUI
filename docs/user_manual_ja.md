## 1. はじめに

KymoTipは、タイムラプス顕微鏡画像から細胞の先端成長ダイナミクスを定量するためのデスクトップアプリケーションです。画像の位置合わせから、SAM2による領域分割、輪郭抽出、軌跡平滑化、中心線抽出、キモグラフ生成、成長速度のグラフ化まで、一連の解析パイプラインを1つのGUIにまとめており、Pythonの実行環境を個別に構築する必要はありません。

画面はタブで構成されており、「0. Input Preview」から「7. Growth」まで、左から順に処理を進めていく作りになっています。あるステージの出力フォルダは、次のステージの入力フォルダとしてそのまま使われる設計なので、基本的には番号順にステージを実行していけばパイプライン全体が完成します。

対象ユーザーは、顕微鏡タイムラプス画像から細胞の伸長速度を計測したい研究者です。プログラミングの知識は前提としていません。

## 2. インストールと起動

### Windows

1. [Releases](../../releases)ページから最新の `KymoTip-<バージョン>-Setup.exe` をダウンロードします。
2. インストーラーを実行します。管理者権限は不要で、ユーザーごとのアプリケーションフォルダにインストールされます。
3. スタートメニューまたはデスクトップのショートカットからKymoTipを起動します。

インストーラーには、SAM2による領域分割専用のPython環境も含めて、動作に必要なものが一式同梱されています。`tiny`以外のSAM2チェックポイントを初めて使用する際には、モデルファイルが自動的にダウンロードされます。このときだけインターネット接続が必要です。

> **注意:** インストーラーはコード署名を行っていません。初回起動時にWindows SmartScreenの警告が表示されることがあります。その場合は「詳細情報」→「実行」を選んでください。

### macOS

現時点では未対応です。

### 動作要件

- Windows 10/11(64bit)
- インターネット接続(`tiny`以外のSAM2チェックポイントを選択する場合のみ必要)

## 3. クイックスタート

初めてKymoTipを使う場合は、まず1セット分のサンプル画像を用意し、以下の手順で0番から7番のタブまで一通り実行してみることをお勧めします。全体の流れを一度体験しておくと、各ステージの役割が理解しやすくなります。

1. **画像を用意する**。タイムラプス画像を `{ファイル名prefix}_{フレーム番号3桁}.{拡張子}`(例: `sample_000.tif`)という命名規則に従って1つのフォルダにまとめておきます(詳細は[5. 入力ファイルの形式・命名規則](#5-入力ファイルの形式命名規則)を参照)。フォルダ名は `00_raw` にしておくと、後述の一括反映がそのまま使えます。
2. **「0. Input Preview」タブを開く**。「Input directory」にその画像フォルダを指定し、「Load frames」でフレームが正しく読み込めるか確認します。
3. **プロジェクト設定を反映する**。同じタブの「Project base directory」に、`00_raw` を含む親フォルダを指定し、「File name prefix」に画像の共通ファイル名部分を入力して、「Apply to All Stages」をクリックします。これで「1. Registration」以降の全ステージの入出力フォルダとファイル名が自動的に設定されます。
4. **「1. Registration」を実行する**。パラメータは既定値のままで構いません。「Run」を押すとフレーム間の位置合わせが行われ、右側のプレビューで結果を確認できます。
5. **「2. Segmentation」で対象を指定する**。「Load Frames from Input Directory」でフレームを読み込み、「Add Object」で解析対象(細胞など)を1つ追加し、プレビュー画像上を左クリックして対象領域を、必要に応じて右クリックで除外領域を指定します。「Run」を押すと、指定した点をもとに全フレームへ領域(マスク)が伝播します。
6. **「3. Contour」〜「5. Centerline」を順に実行する**。いずれも既定パラメータのまま「Run」を押すだけで、輪郭抽出→平滑化→中心線抽出が進みます。プレビューで形状が破綻していないか都度確認してください。
7. **「6. Kymograph」でキモグラフを作成する**。マスクフォルダ・中心線フォルダ・対象ID(既定は `obj0`)を確認し、「Run」を押すとキモグラフ画像が生成されます。
8. **「7. Growth」で成長速度を求める**。「Pixels per micron」と「Time interval」を実験条件に合わせて入力し、「Run」を押すと細胞長・成長速度のグラフとCSVが出力されます。

一連の流れがつかめたら、[6. ステージ別リファレンス](#6-ステージ別リファレンス)で各ステージのパラメータの意味を確認しながら、実際のデータに合わせて調整してください。

## 4. 画面の基本操作

各処理ステージのタブは、共通して次のレイアウトになっています。

- **Input directory / Output directory**: テキスト欄に直接パスを入力するか、「Browse...」ボタンでフォルダを選択します。
- **パラメータ欄**: ステージごとの設定項目です。項目数が多いステージでは縦にスクロールして全項目を確認できます。
- **Run ボタン**: このステージの処理を実行します。処理はバックグラウンドで行われるため、実行中も画面が固まることはありません。
- **進捗バー**: 処理中は表示され、完了すると消えます。
- **Log 欄**: 処理の開始・終了・エラーメッセージが時系列で追記されます。エラーが出た場合はまずここを確認してください。

右側のプレビューは、ステージによってフレームを1枚ずつ送って確認できる画像プレビュー、または輪郭・中心線・グラフを表示するプロットのいずれかになります。「Run」の完了後に自動的に最新の結果が表示されます。

### プロジェクト設定の一括反映

「0. Input Preview」タブには、他のタブには無い専用の項目があります。

- **Project base directory / File name prefix**: 解析対象のプロジェクト全体で共通のベースフォルダとファイル名prefixを指定します。
- **Apply to All Stages**: このボタンを押すと、「1. Registration」から「7. Growth」までの全ステージのInput directory・Output directory・File name prefixが、以下の対応関係に沿って自動的に設定されます。

| ステージ | Input directory | Output directory |
|---|---|---|
| 1. Registration | `{base}/00_raw` | `{base}/01_registration` |
| 2. Segmentation | `{base}/01_registration` | `{base}/02_segmentation` |
| 3. Contour | `{base}/02_segmentation` | `{base}/03_contour` |
| 4. Trajectory | `{base}/03_contour` | `{base}/04_trajectory` |
| 5. Centerline | `{base}/04_trajectory` | `{base}/05_centerline` |
| 6. Kymograph | 画像: `{base}/01_registration`、マスク: `{base}/02_segmentation`、中心線: `{base}/05_centerline` | `{base}/06_kymograph` |
| 7. Growth | `{base}/05_centerline` | `{base}/07_growth` |

この一括反映を使うと、フォルダを毎回手動指定する必要がなくなります。別のプロジェクト(別の画像セット)に切り替えるときは、Project base directoryとFile name prefixを変更して再度Apply to All Stagesを押してください。

### 「Auto-detect from input directory」ボタン

多くのステージには、Input directory内のファイルから「File name prefix」と「Number of frames」を自動推定するボタンがあります。フォルダ内のファイル名が[5. 入力ファイルの形式・命名規則](#5-入力ファイルの形式命名規則)の規則に沿っている場合、このボタン1つでファイル名prefixとフレーム数の入力を省略できます。

## 5. 入力ファイルの形式・命名規則

KymoTipのパイプラインは、フォルダ内の画像ファイルを次の命名規則で認識します。

```
{ファイル名prefix}_{フレーム番号(3桁ゼロ埋め)}.{拡張子}
```

例: `sample_000.tif`, `sample_001.tif`, `sample_002.tif`, …

- フレーム番号は `000` から始まる連番にしてください。フレーム数は、フォルダ内で見つかった最大のフレーム番号+1として自動計算されます(途中の番号が欠けていると、実際の枚数と合わなくなるので注意してください)。
- 対応する画像形式は、TIFF・PNGをはじめとする一般的なグレースケール画像です。8bit・16bitのどちらにも対応しており、16bitの画素値は精度を落とさずそのまま解析に使われます。
- 「Segmentation」タブでフレームを読み込む際は、拡張子が `.png` `.tif` `.tiff` のいずれかであるファイルのみが対象になります。
- 1フォルダ内に複数のprefix・拡張子のファイルが混在している場合、「Auto-detect from input directory」は最も出現数の多い組み合わせを採用します。想定と異なるprefixが検出された場合は、対象外のファイルをフォルダから移動するか、File name prefix欄を手動で修正してください。

### フォルダ構成の考え方

「Apply to All Stages」を使う場合、プロジェクトのベースフォルダの下に、ステージごとの連番フォルダ(`00_raw`, `01_registration`, `02_segmentation`, `03_contour`, `04_trajectory`, `05_centerline`, `06_kymograph`, `07_growth`)が作られていく構成になります。最初に用意するのは `00_raw` フォルダ内の生画像だけで、それ以降のフォルダは各ステージの実行時に自動的に作成されます。

## 6. ステージ別リファレンス

### 0. Input Preview

処理を始める前に、入力フレームを確認するためのタブです。

- **Project base directory / File name prefix / Apply to All Stages**: [4. 画面の基本操作](#4-画面の基本操作)を参照してください。
- **Input directory / Load frames**: 上記のプロジェクト設定とは独立して、任意のフォルダのフレームをその場で確認できます。「Load frames」を押すと、検出されたファイル名prefix・拡張子・フレーム数がステータス欄に表示され、フレームブラウザで1枚ずつ閲覧できます。

### 1. Registration(位置合わせ)

タイムラプス撮影中に生じるフレーム間の位置ずれ・回転ずれを補正するステージです。

| 項目 | 説明 |
|---|---|
| File name prefix(reference channel) | 位置合わせの基準として使うチャンネルのファイル名prefix |
| Number of channels | 1〜3チャンネル。2チャンネル目以降は、基準チャンネルで求めた回転・移動量をそのまま適用するだけなので、それぞれの入出力フォルダとファイル名prefixのみ指定します(基準チャンネルの値から `_ch2` / `_ch3` を付けた候補が自動入力されますが、手動で変更できます) |
| Start angle / End angle / Angle step(deg) | 最適な回転角を探索する範囲と刻み幅 |
| Start frame / Number of frames | 処理対象のフレーム範囲 |
| Reference refresh interval(d) | 基準フレームを何フレームごとに更新するか(0固定なら先頭フレームを基準にし続ける) |
| Noise fill range(n_fill) | 平行移動・回転によって生じる画像端の空白部分を埋めるノイズの輝度範囲 |
| Preview channel | 実行後のプレビューで表示するチャンネルの切り替え |

出力: 位置合わせ後の画像が、入力と同じ命名規則で出力フォルダに保存されます。

### 2. Segmentation(SAM2による領域分割)

SAM2(Segment Anything Model 2)を使い、クリックで指定した点をもとに対象領域(細胞など)を全フレームにわたって自動追跡・領域分割するステージです。

| 項目 | 説明 |
|---|---|
| SAM2 environment root | SAM2用Python環境のフォルダ。インストーラー版では自動的に同梱環境が設定されます |
| Checkpoint | `tiny` / `small` / `base_plus` / `large` から選択。精度が高いモデルほど処理は重くなります。`tiny`以外は初回使用時に自動ダウンロードされます(要インターネット接続) |
| Load Frames from Input Directory | Input directory内のPNG/TIFFフレームを読み込みます |
| Reference frame | クリックで点を指定する基準フレームの番号 |
| Objects / Add Object / Clear Points(this frame) | 解析対象を複数追加できます(例: 複数の細胞を同時に追跡)。「Add Object」で対象を追加し、「Clear Points」で現在表示中のフレームに打った点だけを削除します |
| プレビュー画面でのクリック操作 | 左クリック=対象に含める点(positive)、右クリック=対象から除外する点(negative) |

複数の基準フレームに点を打つことで、途中で形状が大きく変わる対象でも追跡精度を上げられます。「Run」を押すと、指定した点をもとにSAM2が全フレームへ領域を伝播させます。

出力: `mask_{フレーム番号3桁}_{オブジェクトID}.png`(元画像がTIFFの場合は`.tif`)という命名で、フレーム・オブジェクトごとにマスク画像が出力フォルダに保存されます。プレビューには、元画像にマスクを色付きで重ねた結果が表示されます。

### 3. Contour Extraction(輪郭抽出)

領域分割の結果から、細胞形状の輪郭線(x, y座標の順序付き点列)を抽出するステージです。

| 項目 | 説明 |
|---|---|
| File name prefix / Number of frames | 対象ファイルとフレーム数 |
| Mode: Filled mask(skimage) | Segmentationステージが出力した塗りつぶしマスク(`mask_NNN_<object ID>.ext`)から輪郭を抽出します |
| Mode: Ordered outline(ImageJ) | ImageJ等で作成済みの、順序付き輪郭線画像から読み込みます |
| Resort distance threshold(d) | Ordered outlineモードで、点の並び順の乱れを補正する際の距離しきい値 |
| Tracked object ID(mask mode) | Filled maskモードで使用するオブジェクトID(Segmentationで指定したIDと一致させます) |
| Save preview images(PNG) | フレームごとの輪郭プレビュー画像を `images/` サブフォルダに保存します |

出力: フレームごとの輪郭座標を記録した `.txt` ファイル。

### 4. Trajectory Reordering(軌跡平滑化)

輪郭抽出時に生じる点のばらつき・ノイズを、閉曲線に適した方法で平滑化するステージです。

| 項目 | 説明 |
|---|---|
| File name prefix / Number of frames | 対象ファイルとフレーム数 |
| Smoothing method: LOESS | LOESS Degree(多項式の次数)・LOESS fraction(近傍点の割合)で平滑化の強さを調整します |
| Smoothing method: Cyclic moving average | Moving average window size(移動平均の窓サイズ)を指定します |
| Save preview images(PNG) | 平滑化前後を重ねたプレビュー画像を `images/` サブフォルダに保存します |

出力: 平滑化後の輪郭座標を記録した `.txt` ファイル。

### 5. Centerline Extraction(中心線抽出)

平滑化した輪郭から、細胞の伸長方向を表す中心線を求めるステージです。

| 項目 | 説明 |
|---|---|
| File name prefix / Number of frames | 対象ファイルとフレーム数 |
| Extension length(o) | 先端部分を十分に捉えられるよう、中心線を輪郭の外側へ延長する長さ |
| Path trim start/end(m1 / m2) | 計算した経路の始点・終点付近の不安定な部分を切り詰める点数 |
| Moving average window(mm) | 中心線経路に追加でかける移動平均の窓サイズ |
| Save preview images(PNG) | 輪郭と中心線を重ねたプレビュー画像を `images/` サブフォルダに保存します |

出力: フレームごとの中心線座標を記録した `.txt` ファイル。

### 6. Kymograph(キモグラフ生成)

抽出した中心線に沿って輝度をサンプリングし、時間方向に並べたキモグラフ(空間-時間マップ)を作成するステージです。蛍光マーカーの分布変化を1枚の画像で確認できます。1チャンネルまたは2チャンネル(色を重ねた合成画像つき)に対応しています。

| 項目 | 説明 |
|---|---|
| File name prefix(Channel 1) / Number of channels | 1または2チャンネル。2チャンネル目は専用の入力フォルダ・ファイル名prefixを指定します(`_ch2`が自動入力されますが変更可能) |
| Channel 1 color / Channel 2 color | 各チャンネルの表示色(magenta / green / red / cyan / yellow / orangeから選択) |
| Adjust color range to data max | 輝度の表示レンジをデータの最大値に自動調整するかどうか |
| Mask directory / Tracked object ID | Segmentationの出力フォルダと、対象とするオブジェクトID。Segmentationで「Add Object」により付けられたオブジェクト名(例: `obj0`)を指定します |
| Centerline directory | Centerlineの出力フォルダ |
| Number of frames | 処理対象のフレーム数 |
| Normal sample length(px) | 中心線に垂直な方向に、輝度をサンプリングする長さ |
| Figure width / height(in) / Label font size | 出力画像の見た目(図のサイズ・ラベルの文字サイズ) |
| Line width / Estimate optimal line width | キモグラフの各フレームを描画する帯の太さ。「Estimate optimal line width」ボタンを押すと、図のサイズやフレーム数から帯同士に隙間ができない太さを自動計算して設定します。計算値のままだと帯の間にわずかな隙間が残ることがあるため、必要に応じて1〜2ピクセル程度加えて調整してください |
| Pixels per micron | 距離の較正値(1ミクロンあたりのピクセル数) |
| Time interval / Time axis unit | フレーム間の時間間隔(分または秒)。未設定の場合は横軸がフレーム番号になります |

出力: 輝度プロファイルの中間データと、キモグラフ画像(1チャンネルなら1枚、2チャンネルならChannel 1・Channel 2・Mergedの3枚)。プレビューではチャンネルを切り替えて確認できます。

### 7. Growth(成長速度の算出)

中心線データから細胞長の時系列を計算し、そこから成長速度を求めてグラフとCSVに出力するステージです。

| 項目 | 説明 |
|---|---|
| File name prefix(centerline) / Number of frames | 対象ファイルとフレーム数 |
| Pixels per micron | 距離の較正値 |
| Time interval(required) | フレーム間の時間間隔(分または秒)。このステージでは必須項目です |
| Apply LOWESS smoothing / LOWESS degree / LOWESS fraction | 細胞長・成長速度の時系列にLOWESS平滑化をかけるかどうかと、その強さ |
| Figure width / height(in) / Label font size | 出力グラフの見た目 |
| Preview plot | 実行後、Cell length(細胞長)/ Growth rate(成長速度)/ Overlay(重ね描き)のいずれかを切り替えて確認できます |

出力: `{prefix}_growth.csv`(フレーム番号・経過時間・細胞長・平滑化後細胞長・成長速度・平滑化後成長速度の一覧)、および細胞長・成長速度・重ね描きの3枚のグラフ画像。

## 7. プラグイン機能

### 7-1. プラグインの使い方

KymoTipには、標準の7ステージに加えて、ユーザーが追加した測定用タブ(プラグイン)を組み込む仕組みがあります。細胞形状の別指標や、内部構造の分布測定など、標準パイプラインにない解析を追加したい場合に利用します。

- タブバー右上の「**+ Plugins**」ボタンを押すと、利用可能なプラグインの一覧がメニューで表示されます。
- 使いたいプラグインにチェックを入れると、そのプラグインのタブが追加されます。チェックを外すか、タブの閉じるボタン(×)をクリックすると、タブが閉じます(データが削除されるわけではありません)。
- プラグインが1つも見つからない場合、「+ Plugins」ボタンは無効化され、ツールチップにその旨が表示されます。
- プラグインは所定のフォルダに配置するだけで認識されます。配置先はOSごとのユーザーデータフォルダ内(Windowsでは `%LOCALAPPDATA%\KymoTip\plugins`)で、KymoTip自体の再ビルドは不要です。プラグインの入手方法・配置方法は、プラグインの配布元の案内に従ってください。
- プラグインの読み込みに失敗した場合は、起動時に警告ダイアログでエラー内容が表示されます(該当プラグインのタブは追加されません)。

### 7-2. プラグインの開発方法(概要)

自分でプラグインを作成したい場合、KymoTipのプラグインは「入力・出力フォルダ、パラメータフォーム、Runボタン」という標準ステージと同じ枠組みに沿った1つのタブとして実装します。詳しい仕様(必要なクラス構成、実装例)は、本マニュアルの対象外としています。

KymoTipのリポジトリには、Claude Codeを使ってプラグイン開発を進めるためのスキルが同梱されており、そこに詳細な仕様書とサンプルコードがまとまっています。

- リポジトリ内: `.claude/skills/kymotip-plugin-dev`
- Windows版インストーラーでは、このフォルダがインストール先にも `.claude/` としてコピーされるため、リポジトリを取得していなくても、インストール済みのアプリだけでプラグイン開発を始められます。
- `gaussian_fit_detection`(1次元ガウシアンフィッティングによる物体位置・幅検出)は、スキルに同梱の最小サンプルとは別の、実際のプラグイン例です。GitHubのReleasesページからzip形式で入手できます。

## 8. よくある質問・トラブルシューティング

**Q. インストーラー実行時に「WindowsによってPCが保護されました」と表示される**
A. インストーラーがコード署名されていないために表示される警告です。「詳細情報」をクリックし、「実行」を選択すればインストールを継続できます。

**Q. SAM2のチェックポイントのダウンロードが進まない・失敗する**
A. `tiny`以外のチェックポイントは初回使用時にインターネット経由でダウンロードされます。ネットワーク接続を確認してください。社内ネットワークやプロキシ環境では、ダウンロード先へのアクセスが制限されていないかも確認してください。

**Q. 「Auto-detect from input directory」を押しても検出されない**
A. フォルダ内のファイル名が `{prefix}_{フレーム番号3桁}.{拡張子}` の形式になっているか確認してください([5. 入力ファイルの形式・命名規則](#5-入力ファイルの形式命名規則)参照)。対象外のファイル(結果画像や隠しファイルなど)が同じフォルダに混在していると、意図しないprefixが検出されることがあります。

**Q. Segmentationで対象領域がうまく追跡できない**
A. 基準フレームを1枚だけでなく、形状が大きく変化する複数のタイミングで指定し、それぞれに正しい点(positive/negative)を打つと精度が上がります。誤って打った点は「Clear Points(this frame)」で現在のフレームの分だけやり直せます。

**Q. Runを押しても処理が進んでいるのか分からない**
A. 進捗バーが表示されている間は処理中です。Log欄にも開始・終了メッセージが記録されるので、そちらも合わせて確認してください。処理が終わらない場合は、Log欄にエラーメッセージが出ていないか確認してください。

**Q. キモグラフやグラフの見た目を調整したい**
A. Kymographステージの「Figure width/height」「Line width」、Growthステージの「Figure width/height」「Label font size」など、各ステージの表示系パラメータで調整できます。Kymographでは「Estimate optimal line width」で帯の太さの目安を自動計算できます。

## 9. 付録

### 用語集

| 用語 | 説明 |
|---|---|
| キモグラフ(Kymograph) | 空間方向の輝度分布を時間軸に沿って並べた画像。1枚の画像で、ある構造の位置や強度が時間とともにどう変化したかを一覧できます |
| 中心線(Centerline) | 細胞形状の中心を通る、伸長方向を表す線 |
| 輪郭(Contour) | 細胞の外形を表す、順序付きの座標点列 |
| マスク(Mask) | 画像中で対象領域を1、それ以外を0として表した二値画像 |
| SAM2 | Meta社が開発した画像・動画セグメンテーションモデル。クリックで指定した点をもとに対象領域を自動追跡する |
| LOESS / LOWESS | 局所重み付き回帰による平滑化手法。ノイズを抑えつつ全体の傾向を保つために使われる |

### フォルダ命名規則一覧

| フォルダ | 内容 |
|---|---|
| `00_raw` | 生画像(ユーザーが用意) |
| `01_registration` | 位置合わせ後の画像 |
| `02_segmentation` | SAM2によるマスク画像 |
| `03_contour` | 輪郭座標データ |
| `04_trajectory` | 平滑化後の輪郭座標データ |
| `05_centerline` | 中心線座標データ |
| `06_kymograph` | キモグラフ画像・輝度プロファイル |
| `07_growth` | 成長速度グラフ・CSV |

### Segmentation画面での操作方法

| 操作 | 内容 |
|---|---|
| 左クリック | 対象に含める点(positive point)を追加 |
| 右クリック | 対象から除外する点(negative point)を追加 |
| Add Object | 新しい追跡対象を追加(細胞ごとに色分けされます) |
| Clear Points(this frame) | 現在表示中のフレームに打った点のみを削除 |
| Reference frame | 点を指定する基準フレームを切り替え。複数フレームに点を打つことで追跡精度が向上します |
